# README görselleri / README images

README.md ve README.tr.md bu dosyaları kullanır / These files are used by the READMEs:

| Dosya / File | İçerik / Content |
|---|---|
| `icon.png` | Uygulama simgesi / App icon |
| `hero-en.png`, `hero-tr.png` | Ana pencere ve menü çubuğu / Main window and menu bar |
| `screens-en.png`, `screens-tr.png` | Tüm ekranlar, koyu ve açık tema / Every screen, dark and light |

`hero-*` ve `screens-*` örnek içerikle üretilir / are generated with sample content:
`./scripts/screenshots.sh build/shots && swift scripts/make_promo.swift build/shots docs/images build/stories`
